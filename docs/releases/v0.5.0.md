**Breaking release.** Deploy the v0.5.0 server and compatible clients together. Use a fresh
PostgreSQL sync layout and fresh Oversqlite client databases. The HTTP protocol marker stays
`v1`, even though the v0.4.0 wire and durable formats are incompatible.

- Servers require PostgreSQL 17, explicit schema generations, a catalog revision, and
  application-owned deployment readiness. See [Getting Started]({{ site.baseurl }}/getting-started.html).
- Generation discovery replaces capabilities. Compact one-shot pushes replace staged upload and
  committed-row paging. Clients settle and acknowledge durable upload outcomes.
  See the [HTTP API]({{ site.baseurl }}/documentation/api/).
- Go clients open through `NewOpening` and `Advance`. The ready client owns its SQLite
  pool and defers conflicts by default. Compatible generations support coordinated changes
  to columns, tables, and certain foreign keys.
  See [Go SQLite client upgrades]({{ site.baseurl }}/client-upgrades/).
- Clean sync can recover through a sealed snapshot. The server sizes admission per instance,
  and the Go client retries transient capacity refusals within operation-specific windows.
  See [Snapshot recovery]({{ site.baseurl }}/documentation/snapshot-recovery/) and
  [Sizing and deployment]({{ site.baseurl }}/documentation/sizing-and-deployment/).
